# CONTEXT.md — TKS (termes initiaux)

Source normative : `GLOSSARY.md` à la racine. Ce tableau n'est qu'un aide-mémoire.

| Terme | Définition courte |
| ----- | ----------------- |
| Distributeur | Propriétaire de l'application, seul détenteur d'argent. |
| Client | Entreprise qui souscrit une ligne de crédit, commande, rembourse. |
| Agent de service | Employé du distributeur, terrain, travaille hors-ligne. |
| Compte | Connexion (téléphone + mot de passe). États : `EN_ATTENTE_VALIDATION`, `VALIDE`, `REFUSE`, `REVOQUE`. |
| Dossier client | Fiche financière (nom, adresse, créances, plafond). Jamais désigné par le seul téléphone. |
| Commande | Demande d'airtime (`PREPAYE` ou `CREDIT`, canal `EN_LIGNE`/`PRESENTIEL`, paiement `ESPECES`/`MOBILE_MONEY`). Jamais « réalisation » ni « vente ». |
| Créance | Montant dû par un client, une devise (`USD`/`CDF`). |
| Paiement | Montant versé par un client, une devise. Multi-devises par nature. |
| Dette / Reste à payer | Dérivés en CDF au taux en vigueur, jamais saisis. |
| Taux applicable | `1 USD = X CDF`, saisi 1x/jour, ne mord que sur l'USD. Devise pivot : CDF. |
